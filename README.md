📌 Overview
This project is a minimal, fast-loading web application that serves as a digital business card and gateway to my development work. It features an interactive About Me section showcasing my background, skills, and projects, along with direct integration/links to open my GitHub profile.
🚀 Features
•	About Me Section: A dedicated area detailing my bio, technical skills, and key projects.
•	GitHub Integration: Fast one-click access to open and explore my public GitHub repositories.
•	Minimalist Design: Built with plain, vanilla web technologies for lightning-fast load times and zero dependency bloat.
•	Responsive Layout: Formatted to look great on desktop, tablet, and mobile devices.
⚙️ How It Works
•	HTML5: Provides a semantic, clean document structure.
•	CSS3: Delivers responsive styling and modern visual layout.
•	JavaScript: Handles interactive elements, such as dynamic links to redirect or fetch open-source data from GitHub.
💻 How to Run Locally
No complex installation or build tools are required!
Option 1: Direct File Access
	1.	Clone the repository:
git clone https://github.com/your-username/your-repo-name.git

	2.	Navigate to the project directory:
cd your-repo-name

	3.	Open the site:
•	Double-click index.html to launch it directly in your default browser.
Option 2: Using a Local Development Server (Recommended)
If you are using VS Code:
	1.	Install the Live Server extension.
	2.	Open the project folder in VS Code.
	3.	Right-click index.html and select "Open with Live Server".
Alternatively, run Python's built-in HTTP server:
python3 -m http.server 8000

Then open http://localhost:8000 in your browser.
